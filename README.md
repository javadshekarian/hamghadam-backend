## 📖 Overview

**Addiction Recovery System** is a desktop application built with **Java** that aims to provide a safe, supportive, and motivating environment for individuals walking the challenging path toward recovery from addiction. The project combines **technology** with **empathy** to create a bridge between patients, families, and care teams.

> 💡 This project is being continuously and incrementally developed. Every release aims to deliver a more complete, more reliable, and more human experience.

## 🚀 Installation

### Prerequisites

Before getting started, make sure the following tools are installed on your system:

- **Java JDK 17** or higher
- **Maven 3.8+**
- **Git**
- A supported database (SQLite is used by default)

### Setup Steps

```bash
# 1. Clone the repository
git clone https://github.com/username/addiction-recovery.git

# 2. Enter the project directory
cd addiction-recovery

# 3. Build the project with Maven
mvn clean install

# 4. Run the application
mvn javafx:run
```

### Default Login

After launching the application for the first time, you can use the default credentials below:

```text
Username: admin
Password: admin
```

> ⚠️ Please change the default password immediately after your first login.
